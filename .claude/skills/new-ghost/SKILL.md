# テンプレートから独立したゴーストを作る

AGENTS.md の「独立ゴーストにするときのチェックリスト」に沿って進める。

1. 次のことをユーザーに聞く。推測で決めない。
   - ゴーストの名前（descript.txt の `name`、install.txt の `name`）
   - `\0` 側と `\1` 側のキャラクター名と、それぞれの一人称・口調・性格
   - 作者名（`craftman` は半角英数、`craftmanw` は表示名）と作者の URL
   - インストール先のフォルダ名（install.txt の `directory`。半角英数で、他のゴーストと重ならないもの）
   - ネットワーク更新をするか。するなら更新ファイルを置く URL
   - シェルをどうするか（`shell/master/` は CC BY-NC-ND なので、改変した画像は配布できない）
2. 変更するファイルと内容を一覧にして見せ、了承を得てから編集する。
3. 編集が終わったら `tools/check.ps1` を通す。
4. ややめとマック朗に固有の台詞（自己紹介、ランダムトーク、マウス反応など）をどうするか相談する。書き換える場合は、辞書ファイルごとに少しずつ進め、そのつど確認してもらう。
